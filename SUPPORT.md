# Support

Use [GitHub Issues](https://github.com/teslashibe/codex/issues) for reproducible bugs and focused feature requests. Include the package version or commit, Go version, operating system, Codex CLI version, and a minimal reproduction with secrets removed.

This project does not provide guaranteed response times or private implementation support. General Codex CLI installation, authentication, model availability, account, and service questions belong with the [OpenAI Codex CLI](https://github.com/openai/codex) or OpenAI support.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
